# 改动检查清单

适用于人和 AI 助手（Claude、Codex 等）。每一条都来自 2026-10-31 实际发生过的问题，括号里是当时的例子。
不必每次全做：按改动类型挑对应的一节；「每次提交前」一节总是要做。

## 一、接入设备的新接口或新字段之前

- [ ] **先从真机取一次原始返回值**，确认字段名、类型和缺失情况，再写解析代码。
  （文件大小以字符串返回，按整数解析导致整列显示「—」；单元测试照着假设写数据，所以没测出来。）
- [ ] **测试数据从真机返回值摘取**，不要凭参考实现或文档手写。
- [ ] **会改动设备的操作，先用自己建的测试条目实测边界行为**，再写确认文案。
  （删除非空文件夹：设备会递归删除，而不是拒绝。）
- [ ] 只操作测试文件和测试文件夹，结束后清理；列目录时不打印用户的文件名。
- [ ] 解析设备输出时整体解析 JSON，不要按行切分。
  （文件名含 Unicode 分隔符，Python `splitlines()` 会把 JSON 切断。）

## 二、改界面之后

- [ ] **窄窗口**：把窗口缩到最小宽度，检查有没有内容被裁切或被挤出可视范围。
  （右栏三步图示撑开整列；表格名称列把日期挤到横向滚动区外。）
- [ ] **三种语言**：`gui/l10n-sync.sh` 后没有未翻译和失效条目；用英文和日文各启动一次看。
- [ ] **空状态、加载中、出错状态**都看一眼，旧的出错消息在成功后会被清除。
- [ ] **跳转与首次加载的顺序**：从别处跳进一个页面时，页面自己的首次加载不能覆盖跳转结果。
  （从最近投递跳到设备文件，停在了根目录。）
- [ ] **同名的按钮或入口**不能出现在同一屏上，除非它们做同一件事。
  （设置页上两个「设置向导…」，一个是完整向导，一个只设快捷键。）
- [ ] **只有图标的按钮**用 `Label(…, systemImage:).labelStyle(.iconOnly)`，不要只靠 `.help`。
  （读屏软件读到「Ipad」「移动」这类 SF Symbol 名称。）
- [ ] **工具栏里不用 `Toggle`**：它在工具栏构建时会写入绑定。（App 启动就跳到设置页。）

## 三、决定一个功能放在哪里、叫什么

- [ ] **按它作用的范围放，不按它在哪里被做出来放。**
  （最近投递覆盖所有入口，却放在快捷投递页；设备文件不是投递方式，却做成第五个投递标签；
  ⌃1 与 Finder 共用的排版，只放在快捷键页。）
- [ ] **名字要能和相邻的东西区分**。（Finder 右键出现后，「快捷投递」不再能指代 ⌃1。）
- [ ] **状态只写能检测到的**；检测不到就如实写来源，不写结论。
  （Finder 服务无法查询开关，原先写死「已启用」；只看 USB 总线会把「网络未就绪」报成已连接。）
- [ ] 全文统一用词：动词用「投递」，品牌写作 QUADERNO，App 名 TrueScale for QUADERNO。

## 四、功能边界变化时，同步所有对外文字

- [ ] README、App「关于」页、`docs/DIRECT-DELIVERY.md`、CHANGELOG、发布说明。
- [ ] 正在准备的对外信件或公告。
  （加入删除功能后，给富士通的信仍写着「不会删除任何文件」；Finder 菜单改名后信里仍是旧名。）
- [ ] 直连工具的消息表 `MESSAGES` 与 App 文案一致，三种语言都有。

## 五、每次提交前

- [ ] `tests/test_direct_delivery.py` 全部通过（使用 `.build/direct/venv/bin/python`）。
- [ ] 改了直连工具：先 `zsh direct/build-helper.sh`，再 `zsh gui/build-app.sh`，否则 App 里打包的是旧版本。
- [ ] 改了服务名或 App 路径：`lsregister` 中只剩一份当前登记（`lsregister -dump | grep "service id"`），
  旧的测试构建要注销，否则 Finder 菜单会出现重复项。
- [ ] 在真机上至少走一遍受影响的入口；做不到时，在提交说明里写明哪些没验证。

## 六、发布前

- [ ] Xcode「设置 → 账户」已登录有云签名权限的账号（API 密钥默认没有该权限）。
- [ ] `gui/release-github.sh` 会核验直连运行时的每个 Mach-O 都是 Developer ID + Hardened Runtime。
- [ ] 推送前扫描全部未推送提交的历史（不只是最终版本）中有无凭据、私钥、设备序列号、个人路径。
