# PDF 语义重排方案（提案，尚未实现）

目标是让 A4 内容在 QUADERNO A5 上保持可读字号；允许页数及版式变化。
设备显示区使用项目实测尺寸 157.1 × 209.5 mm，不等同于 ISO A5 纸张。

## 接入现有排印管线

PDF → 文字/版面读取 → 文档语义模型 → Pandoc JSON AST → 现有过滤器 → Typst → PDF。
Pandoc 当前没有 PDF 输入 reader，因此主要新增工作是 PDF 的读取和语义重建。
标准纸张、设备尺寸、字体、繁体输出、预览和投递复用既有能力。

## 文档模型

统一节点包括标题、段落、列表、表格、图片、图注、脚注、公式和代码。
每个节点保存源页码、原区域坐标、阅读顺序、原始内容及需要复核的识别问题。
中间结果使用带版本的 JSON 保存，避免每次调整字体/页边距都重新 OCR。
Pandoc JSON 是排版交换格式；来源坐标和识别问题保留在独立模型中。

## 读取策略

- 有文字层：提取字符与坐标，恢复段落、栏顺序、标题层级和重复页眉页脚。
- 扫描页或文字层损坏：按页 OCR，再恢复结构。不能仅根据“可复制”判断文字层可靠。
- 表格：保存行列和单元格；无法可靠恢复时保留原区域，不猜补数字或缺失内容。
- 公式/复杂图：优先保留原区域；使用排版器支持的矢量格式，必要时保留高分辨率图像。

Docling 可作为语义读取器候选，需用本项目样本验证准确性、运行资源与打包成本。
不以“转成 Markdown 成功”作为内容完整或阅读顺序正确的证据。

## 输出与校验

正文按目标行宽重排，中文正文以 10.5pt 为初始可读性基准，可由用户调整。
大表格和图采用拆分、横向或分区域展示，避免为了塞进一页而整体缩成小字。
校验正文字符、数字、表格行列、图片及脚注引用；保留节点到原页的对应关系。
低把握节点保留来源供对照，不将推断当作原文事实。

首批验证样本应包含：单栏长文、双栏论文、含表格图注的报告、扫描书籍。
验收重点：内容无遗漏、阅读顺序正确、字号可读、复杂区域有可靠保留方式。
