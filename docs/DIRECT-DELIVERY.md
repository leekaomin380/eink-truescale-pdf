# 设备直连与剪贴板命名

2026-10-31：投递通道已从官方客户端 `--print` 改为设备 HTTPS API。

## 日常使用

- Ctrl+1：剪贴板 Markdown 渲染为 PDF，自动命名后直传到设备 `Document/Received/`。
- 命名顺序：YAML `title` → 第一个 Markdown 标题（一级至六级，排除代码块）→ 第一条正文的首句 →「剪贴板摘录」。取前 32 字，清理非法字符，附加 `YYYYMMDD-HHMMSS`。
- App 内：手动标题规则不变，发送按钮同样走设备直连。
- 上传完成后回读 PDF，核对 SHA-256，并查询目录确认文件 ID；保存与校验完成后发送打开文档请求。App 显示 Received 保存路径，并区分已请求打开与打开请求失败；不将打开请求被接受等同于屏幕确认。
- 已存在同名文件时另取唯一文件名；不覆盖设备文件，不删除已有文档。
- 失败保留本地 PDF，快捷投递错误通知显示路径。

## 当前设备配置

当前设备为 USB 网络连接的 FMVDP51，设备主机名 `Android.local`。
配对凭据首次从这台 Mac 已有的官方配对中迁移。其后保存到
`~/Library/Application Support/Quaderno Converter/Direct/`，目录权限 700，文件权限 600。
常规检查和上传不读取官方配置，也不启动官方 App。

App「快捷投递 → 设备直连」提供迁移入口和自检。尚未配对的新设备目前仍需先取得已有配对；独立 PIN 首次配对尚未实现。

Wi-Fi 地址可填写设备 IP，但本次只完成 USB 实机验收，Wi-Fi 切换与断线重连尚未验收。

## 网络与证书

首次迁移用 macOS curl 验证设备证书链和 canonical hostname `digitalpaper.local`，并固定设备公钥。
后续请求由系统 curl 直连 USB / 局域网，绕过系统代理；以固定的 SPKI SHA-256 验证设备身份，不依赖官方 App 安装的信任根。
证书或公钥变更会连接失败，不自动接受新设备身份。
凭据不写进命令行、应用包或仓库。

## 构建与验证

1. `zsh direct/build-helper.sh`：用 uv 建立构建环境，按锁定版本打包独立运行时。
2. `zsh gui/build-app.sh`：打包并签名 App、渲染引擎和直连工具。
3. 使用构建环境 Python 运行 `tests/test_direct_delivery.py`。
4. `deliver.sh --check` 只渲染测试 PDF、认证并读取设备根目录，不上传文件。

协议参考：https://github.com/janten/dpt-rp1-py 。当前 helper 只实现认证、目录查询、创建文档、上传及回读，不提供删除、同步或固件更新。

## 同名主机修正（2026-10-31）

实机出现 `Android.local` 同时解析到局域网 Android 设备和 Quaderno USB 地址的情况。
直连工具现枚举 macOS mDNS 的全部地址，保留 IPv6 接口作用域，并优先尝试正在发布
`_dp_fujitsu._tcp` 服务的网络接口。每个候选仍必须通过已保存的公钥校验。
只在认证前的只读 nonce 查询阶段尝试候选地址；认证后固定连接，不对文件创建或上传做跨地址重试。
无需改名、固定设备 IP 或重新配对。

App、Ctrl+1 与自检共享跨进程互斥锁，完整串行执行认证和文件事务，避免同一设备的 nonce / session 相互干扰。锁随进程退出自动释放；等待超时提示另一项投递正在进行，不伪报为网络连接失败。

## 保存位置与设备显示修正（2026-10-31）

通过设备截图确认用户停留在 `System Storage > Received`，旧直连却把文件放在 `Document/` 根目录，所以该列表内看不到新文件。设备中原有文件保留原位。

新投递统一进入 `Document/Received/`；回读和目录核对后，通过 `/viewer/controls/open2` 请求打开新文件。打开失败时仍报告文件已保存的精确位置，不伪报上传失败，避免用户重复上传。

用户在手动补发打开请求后确认收到，设备截图也确认验收正文已显示。

## 快捷投递排版与提速（2026-10-31）

Ctrl+1 默认共享「文件、文本、网页」当前共用的字号、字体、行距、页边距、页面尺寸及页脚时间。App 每次参数变化都原子写入 `~/Library/Application Support/Quaderno Converter/clipboard-layout.json`（600 权限），所以退出 App 后仍可使用最后保存的配置。

「快捷投递 → Ctrl+1 排版」可开启独立排版。首次开启复制共用值，之后独立修改；关闭开关恢复跟随，保留独立配置供下次使用。“从共用设置重新复制”可重置独立配置。

提速包括：缓存已认证的接口地址（绑定原公钥，失效仍重新发现）、合并一次工具启动、认证与本地渲染并行、上传完成立即请求打开，随后完成回读和目录校验，最终成功提示仍等校验通过。

默认及已导出的本地字体可使用缩小扫描范围；数学、未知文字脚本或字体文件不可用时保留完整系统字体回退，不依赖不存在的字体缓存。

同一合成短文的单次脚本对照：旧版约 4.38 秒，新版默认共享排版约 1.75 秒（包含回读校验，关闭了通知用于比较；不包含快捷键系统调度和墨水屏刷新，不代表长文或多图内容时延）。独立 14pt 与共享 10.5pt 已分别从设备回读 PDF，验证字号发生变化且共用设置未被改动。验收后恢复默认共享模式。
