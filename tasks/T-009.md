## 3. 已知缺陷（这是本任务的核心，必须修掉）

**缺陷 A：外侧栏图注被插进正文段落中间。**

本书版式是单栏正文 + 宽外侧栏，图注排在外侧栏里，奇偶页镜像。
模型把外侧栏的图注块当作正文流的一部分，插进了正文段落中间。

实证（JSON 第 33 项，印刷 177 页），`markdown.text` 实际输出为：

```
…可导致多个而非单个离子通道的激活（图6.30）。
G蛋白耦联的第二信使级联反应的信号放大作用。当递质激活了G蛋白耦联受体时…   ← 图注混入
信号放大存在于级联反应的多个环节，1个神经递质分子与…                    ← 正文续
```

正文段落被图注腰斩。该页 `block_order` 是 1=图注标题「图6.30」、2=正文、3=空块、4=正文续。

## 4. 要做的事

用 Python 写一个**通用**脚本（不要把第 6 章的数值硬编码，JSON 路径 / PDF 路径 / 输出路径都走命令行参数），
放在 `tools/scan2epub/` 下。步骤：

**(1) 图片本地重裁 —— 不要下载 bcebos URL**

从原始 PDF 按 bbox × 2.777778 裁 400 dpi 区域。
推荐用 `pdftoppm -r 400 -x X -y Y -W W -H H -f N -l N -png`，
它直接渲染指定区域，不需要 Pillow 做裁剪。

- 转**灰度**（目标设备 QUADERNO A5 Gen.2 是黑白屏）
- 最长边缩到 ≤ 1200 px（设备版心 137 mm @ 227 ppi）
- 存 JPEG q85
- macOS 自带 `sips` 可做灰度与缩放；若用 Pillow 请在 `tools/scan2epub/.venv` 里装，**不要污染系统 Python**

**(2) 可视校验（必做，不可跳过）**

裁完后，挑 **3 张**图（至少含 p33 那张 `[24,122,748,979]`），
把裁出的图与原页整页渲染并排存到 `tools/scan2epub/_check/`，
并在报告里写明你如何确认裁切区域正确。**如果坐标映射错了，后面全白做。**

**(3) 缺陷 A 修复：外侧栏剥离**

不要凭空猜阈值。**用数据推导**：统计各页 `text` 块 bbox 的 x 分布，
按印刷页奇偶分别求出正文栏边界，把落在外侧栏的块从正文流摘出，
作为图注附到纵向最接近的那张 `image` / `chart` 之后。

先调查 `group_id` 是否已经把图与其图注分到同组；若是，直接用它，比几何规则更可靠。

**验收必须覆盖 p33。**

**(4) 缺陷 B 处理**

逐个核实 9 个空块的内容是否已在别处出现。已出现 → 丢弃；未出现 → 报告，不要静默吞掉。

**(5) 跨页段落合并**

markdown 是逐页的，跨页段落会断成两段。
规则：上页最后一个正文块不以 `。？！："》）` 等收尾标点结束，且下页第一个块不是标题类
（`paragraph_title` / `doc_title` / `figure_title`）→ 合并。

**(6) 组装 EPUB**

- 用 `paragraph_title` 的层级生成章节结构与 TOC
- 图片以相对路径内嵌
- 填元数据（书名、作者、语言 zh-CN）
- 用 `pandoc` 生成，输出到 `~/Desktop/神经科学-第6章-神经递质系统.epub`

**(7) 过本仓已有管线出设备 PDF**

```
./book.sh ~/Desktop/神经科学-第6章-神经递质系统.epub --lang zh --size 13pt \
  -o ~/Desktop/神经科学-第6章-神经递质系统-quaderno.pdf
```
