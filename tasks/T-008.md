## 3. 任务

### ① 中文字体下拉显示中文名（先做，最简单）

现状：`gui/mac/ContentView.swift` 第 230 行附近的中文字体 Picker 直接显示
`vm.cjkFonts` 的原始值，界面上呈现为 `PingFang SC` / `Songti SC` / `Heiti SC` …

要求：显示中文名，但**选中值必须仍是 typst 认得的原始字体名**。

⚠️ **这里有个会静默毁掉排版的陷阱**（T-002 时已记录）：若把 Picker 的 tag/value
也改成「宋体」，传给 `book.sh --font 宋体` 后 typst 找不到该字体会**静默 fallback**
到别的字体 —— 用户看不出任何报错，但排版已被悄悄换掉。
**中文名只能是显示层。**

映射表直接采用 `gui/index.html` 的 `CJK_NAMES`（苹方 / 宋体 / 黑体 / 华文宋体 /
冬青黑体 / 思源宋体 / 思源黑体…）。表中没有的字体，**原样显示其英文名，不要瞎译**。

显示格式建议沿用网页版：`宋体（Songti SC）`，兼顾可读与可核对；若你认为在
macOS Picker 的窄宽度下只显示中文名更好，可以那样做并在报告中说明理由。

西文字体（Times New Roman、Charter 等）**保持英文**，它们没有通行中文名。

### ② 页面右下角打印时间

要求：渲染出的 PDF 每页右下角显示生成时间，格式 `2026-07-30 09:15`（年月日 时:分）。

实现位置：`deliver.typ`（页脚）。注意几件事：

- **页码现在在页脚居中**（见现有模板的 `pagenumbering`）。新增时间不要与页码冲突，
  建议时间靠右、页码保持居中，或页码居中 / 时间右下角。
- **字号要小、颜色要浅**，但**不能太浅**：项目文档 `docs/typography-for-eink.md`
  记录了一条推论 ——「16 级灰阶下，浅于约 40% 的灰在墨水屏上接近糊掉」。
  建议不浅于 `luma(100)`，并在报告中说明你用了什么值。
- **必须可关闭**：新增一个 typst 变量（如 `$if(printtime)$`），由 `book.sh`
  用命令行开关控制（如 `--no-time` 或 `--time`），**默认行为由你提议**，
  在报告中说明并给出理由。委托方倾向「默认开启」，因为用户正是为此提出需求。
- 时间从哪来：typst 的 `datetime.today()` **只有日期没有时分**。
  时分需要由 `book.sh` 在调用时通过 `-V` 传入（用 `date` 命令取）。
  这是本项目一贯的做法：能在 shell 侧确定的事，不要在模板里绕。

### ③ 参数区分层折叠

现状：侧栏参数区有 6 项常驻（目标设备、中文字体、西文字体、正文字号、页边距、行距），
加上第 ② 项的页脚开关会更挤。

要求：分成两层。

| 层 | 内容 | 默认状态 |
|---|---|---|
| 常用 | 正文字号、行距 | 常驻可见 |
| **进阶**（可折叠） | 目标设备、中文字体、西文字体、页边距、页脚时间开关 | **默认收起** |

理由（供你理解取舍，不必照搬文案）：字体与目标设备是**一次性设定**，调好后几乎不再动；
字号与行距才是**每篇可能微调**的。

实现建议：用 SwiftUI 的 `DisclosureGroup`，标题如「进阶设置」。
折叠状态**应当记住**（用 `@AppStorage` 持久化），否则每次开 app 都要重新展开。

> 附带说明：本项目当前**完全没有做设置持久化**（`UserDefaults`/`@AppStorage`
> 出现次数为 0），字体字号等每次启动都回到 `config.sh` 默认值。
> 那是一个独立的待办，**本任务不要顺手实现它** —— 只持久化折叠状态即可。
> 若你认为顺带做了更省事，请在报告中提出，由委托方决定，不要自行扩大范围。

## 7. 边界与禁止事项

- 中文名只能是显示层，Picker 的选中值必须是原始字体名（见 §3① 的陷阱说明）。
- 不要顺手实现全量设置持久化（见 §3③ 的附带说明），只持久化折叠状态。
- 改 `deliver.typ` 时特别小心 —— 该文件近期出过两次事故：
  ① `#show heading: it => block(...)` 构造容器，与分章的 `pagebreak` 冲突，
     整本 EPUB 渲染中止（正确写法是 `#show heading: set block(...)`）；
  ② `heading` 没有 `spacing` 参数。
  **凡改该文件，必须同时验证 plain 与 EPUB 两条路径。**
- 不引入任何第三方依赖。
- 不要 git commit / push / 改 .gitignore。
