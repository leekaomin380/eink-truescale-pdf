TrueScale for QUADERNO · English

隐私政策

更新日期：2026 年 11 月 14 日

TrueScale for QUADERNO 是独立的第三方 macOS 文档排版与设备投递工具，不隶属于 FUJITSU 或 QUADERNO。无需开发者账户，不含广告、跟踪或分析 SDK，不向开发者上传文档、配对资料或使用记录。

本机处理与保存

导入的文档、文本、网页正文、排版设置、恢复草稿、待投递 PDF 和投递记录保存在本机，用于恢复编辑、排队与重试。文件转换在本机进行。文稿不会为转换而上传开发者服务器。投递成功的记录和本机副本可能继续保留，除非你通过应用或系统管理文件将其移除。

网页和设备连接

你主动输入网页链接时，应用访问相应网站提取文章及其图片。来源网站会收到正常网络请求信息，例如 IP 地址。应用不绕过登录或付费墙。你主动投递或管理设备文件时，文档和相关操作直接发送到已配对的设备。设备配对密钥和证书校验信息只保存在本机，用于验证设备身份，不发送给开发者。

文件授权、剪贴板与快捷键

应用读取你选择、拖入或主动通过快捷键投递的内容。设备截屏功能读取的是 QUADERNO 屏幕，并保存到你设置的位置。商店版通过系统文件选择窗口获得文件或目录访问授权；部分目录使用本机安全书签保留授权。应用不会持续上传剪贴板内容。

反馈与联系方式

若你主动通过电子邮件或 GitHub 提供诊断信息，这些服务按各自政策处理信息。请在发送前移除文档正文、设备密钥和其他私人内容。联系：leekaomin@foxmail.com。数据处理方式变化时会更新本政策。

Privacy policy

Updated November 14, 2026. TrueScale for QUADERNO is an independent third-party macOS tool, unaffiliated with FUJITSU or QUADERNO. It requires no developer account and includes no advertising, tracking or analytics SDK.

Conversion takes place locally. Imported documents, text, extracted articles, settings, recovery drafts, queued PDFs and delivery history are stored on the Mac. Local copies and history may remain until removed through the application or system file management. Documents, pairing keys and usage history are not uploaded to the developer.

When you supply a web URL, the application requests that page and its original images directly. Source websites receive normal network-request information, including IP addresses. The application does not bypass logins or paywalls. Delivery and device-file operations communicate directly with your paired reader. Device keys and certificate pins remain on the Mac.

The application processes content you select, drag in, or explicitly send using a shortcut. Device screenshots capture the QUADERNO display and are saved locally. The Mac App Store edition uses system file selection and local security-scoped bookmarks for authorized file and folder access. It does not continuously upload clipboard content.

Voluntary email or GitHub feedback is handled by those services. Remove private documents and device credentials before sending diagnostic information. Privacy contact: leekaomin@foxmail.com. This policy will be updated if processing changes.
