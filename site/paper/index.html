清样

把好文章，排成好读的文稿。

点击 Safari 工具栏上的纸张图标，提取当前网页正文，去除导航等干扰，按你选择的字体与纸张重新排版，再打印或存为 PDF。选中文字时，优先整理选中部分。

Safari App Store 版本准备中。当前桌面版面向 macOS，无需电子纸设备。

读起来像一份文稿

  • 保留正文结构、图片与说明、表格、代码和链接。
  • A4、A5、Letter 纸张；调整西文字体、中日韩字体、字号、行距和页边距。
  • 简体中文、繁体中文、English、日本語界面，文章原文语言不变。
  • 本机处理，文章不上传开发者服务器，无需注册账户。

使用方法

  1. 安装并打开清样，点击“打开 Safari 扩展设置”，启用扩展。
  2. 打开普通网页文章，点击 Safari 工具栏的纸张图标。
  3. 在文章页右上角“设置”中调整版式。也可从 Safari 扩展设置进入独立设置页。
  4. 在系统打印窗口选择“存储为 PDF”，或选用你的打印机。首次使用可关闭浏览器页眉与页脚。

常见问题

不是所有网页都能提取。浏览器内部页、内置 PDF 阅读器、受限嵌入内容和部分特殊网页不适用。正文识别不理想时，可先选中需要的文字再点击插件。不会绕过登录、付费墙或网站访问限制。

字体取决于本机。未安装的字体会自动使用回退字体；不会从网络下载字体。中文和日文字体菜单中的类别使用系统可用字体。

图片需要来源网站可访问。原图载入失败时，会保留原图链接并提示；这时不会自动打开打印窗口，方便你先检查。

清除本地文章。在独立设置页选择“清除暂存文章”。该操作保留字体等偏好。临时记录也会在后续使用或关闭文章页时按规则清理。

TrueScale Paper

Turn a web article into a quiet, readable document. Reconstruct the article locally, choose fonts and paper layout, then use the system print dialog to print or save a PDF. Tables, illustrations, code and source links are preserved where extraction supports them.

Enable the extension in Safari Settings, open an article and click its paper icon. Select text first to capture only that portion. Use Settings on the reader page for fonts, spacing, paper size, interface language and image preferences. Turn off browser headers and footers in the print dialog if you prefer a clean page.

Uses installed system fonts with fallbacks. It does not bypass paywalls or access controls, and some pages cannot be extracted. Original images load from their source websites. No account or developer-server article upload. Contact the support email below for help.
